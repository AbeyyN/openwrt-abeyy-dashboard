# OpenWrt Abeyy Dashboard

Dashboard ringan untuk OpenWrt/ImmortalWrt.

## Ciri
- CPU, RAM, storan dan uptime
- Live download/upload
- Graf Chart.js
- Senarai DHCP clients
- Usage hari ini dan bulan ini melalui vnStat
- PWA asas
- Struktur HTML/CSS/JS berasingan

## Pasang
```sh
chmod +x install.sh
./install.sh
```

Buka `http://192.168.1.1/dashboard/`

Config interface: `/etc/abeyy-dashboard.conf`
